# AI Travel Agent

A beginner-friendly Python-based AI Travel Agent that helps users plan their trips.

## Features

- Destination suggestions based on budget
- Day-by-day itinerary generation
- Travel budget planning
- Travel tips
- Interactive command-line interface

## Technologies Used

- Python
- Data Structures
- Functions
- Conditional Statements
- Loops
